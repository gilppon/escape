# 키링 펫 매트릭스 · Keychain Pet Matrix

오리지널 픽셀 친구 **모모**를 돌보면 가상의 저폴리 기억 도시에서 지정된 오류 차단물이 바뀌는 React 브라우저 게임입니다. 화면 오른쪽의 실제 SVG 픽셀 액정, 왼쪽의 WebGL 도시, 이벤트 카드, 지도, 기록, 옵션은 하나의 게임 상태를 사용합니다.

## 실행

- 설치: `npm install`
- 개발: `npm run dev`
- 빌드: `npm run build`
- 로컬 미리보기: `npm run preview`
- 순수 상태 자동 검사: `npx tsx src/run-tests.ts`
- 타입 검사: `npx tsc --noEmit`
- 의존성 보안 상세 검사: `npm audit`
- 브라우저 내 검사: **설정 → 게임 규칙 자동 검사**. 실제 진행 데이터를 변경하지 않는 독립 상태로 실행하며, 실패 항목을 숨기지 않습니다.

회원가입, API 키, 서버, 유료 서비스는 필요 없습니다. 빌드 도구의 원래 단일 HTML 출력 구성을 유지합니다. 최초 페이지 로드 이후 게임에서 외부 네트워크 요청을 하지 않습니다. 서비스 워커/PWA 설치 기능은 추가하지 않았으므로 오프라인 최초 접속까지 보장하지는 않습니다.

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 민호 이동 |
| 마우스 드래그 / 화면 드래그 | 제한된 범위의 카메라 회전 |
| 바닥 클릭 / 탭 | 해당 위치로 이동, 차단물 앞에서 정지 |
| 자원 클릭 / 탭 | 가까우면 수집, 멀면 이동 |
| E / Enter | 근처 자원 수집, 출구 조사, 준비된 이벤트 확정 |
| Tab | 장치 열기/닫기, 도시 일시정지 |
| 1~5 | 장치가 닫혔으면 돌봄 선택 후 열기, 열렸으면 돌봄 실행 |
| Q | 이벤트 대상과 결과 안내 |
| M | 지도 |
| Escape | 일시정지 / 메뉴 닫기 |

모바일은 방향 패드, 조사 버튼, 장치 버튼, 이벤트 카드를 사용합니다. 지도에는 자원으로 이동하는 버튼과 이전 구역 재방문 버튼이 있습니다. 이동은 물리 장애물을 통과하지 않습니다. 키 설정, 감도, 카메라 반전, 터치 크기/위치, LCD 확대, UI 배율, 고대비, 색각 보조, 노이즈/스캔라인/색수차/흔들림, 모션 감소, 분변 효과 감소, 자막, 내부/외부 음량과 음소거를 제공합니다.

## 연결 구조

- `src/game.ts`: 펫, 자원, 구역, 차단물, 공유 게임 시계, 이벤트 큐, 저장 검증, 순수 상태 변경 함수.
- `src/World.tsx`: Three.js 도시와 민호, 제한된 이동 충돌, 클릭 선택, 고정 시드 낙하, 픽셀 잔해, 거대 현신.
- `src/PixelPet.tsx`: 4톤 LCD와 오리지널 SVG 픽셀 모모, 행동별 애니메이션.
- `src/App.tsx`: 공유 상태 소유, 100ms 논리 시계, 장치 전환, 모달, 입력, 자동 저장과 UI.
- `src/tests.ts`: 32개 순수 게임 규칙 검사.
- `src/run-tests.ts`: 동일 검사를 CLI에서 실행.

`care(state, action)`는 자원과 배터리를 소비하고 펫 상태를 갱신한 뒤 `sourceCareActionId`, `targetBarrierId`, `seed`를 가진 이벤트를 정확히 하나 생성합니다. 이벤트 상태는 `queued → aiming → falling → resolved`. 내부 애니메이션 뒤 외부 조준 확인을 거치며, 실행 시 `startedAt`이 공유 시계에 기록됩니다. 3D 렌더러는 프레임 수가 아닌 게임 시각으로 시드 궤적을 표시합니다. 해결 함수는 현재 구역, `glitchBarrier` 태그, 이벤트 종류, 대상 ID를 검사합니다. 일반 건물, 민호, 모모는 해제 대상이 될 수 없습니다.

차단물은 시각적으로 blocked → crumbling → cleared 순서로 바뀝니다. 렌더러가 일반 물리 파괴를 일으키는 대신 검증된 명시적 상태 변경을 요청합니다. 이벤트당 효과 그룹은 최대 18개이고, 분변 감소 모드는 6개입니다. 종료 시 효과 지오메트리를 제거합니다. 정적 도시는 재질별 메시 병합, 구역 전환 시 전체 GPU 자원 해제, DPR 상한을 사용합니다.

## 돌봄과 이벤트

| 돌봄 | 내부 결과 | 외부 결과 |
|---|---|---|
| 밥 | 배고픔 -35, 분변 +25, 애정 +7 | foodRain: 지정 식탐/셔터 오류 해제 |
| 청소 | 분변 -55, 건강 +8, 애정 +7 | wasteMeteor: 지정 오염 오류 해제 |
| 놀이 | 기분 +22, 애정 +18 | pixelSignal: 숨은 경로 연결 |
| 수면 | 에너지 +40 | moonPause: 회전 오류를 정지시키고 안전 경로 고정 |
| 픽셀 충전 | 건강 +25 | warmPulse: 장치 안정화, 조준 거리 18 → 30 |

4초 쿨다운, 배터리와 음식/키트/카세트 자원이 적용됩니다. 이미 준비된 이벤트가 있거나 대상이 없으면 새 돌봄을 실행하지 않습니다. 이로 인해 자원을 무한 소비하는 경로를 막습니다. 건강은 자연 감소로 바닥나지 않습니다. 오프라인 경과 시간은 적용하지 않습니다.

## 세 구역과 엔딩

1. **학교 뒤 골목**: 음식 비와 분변 운석으로 2개 오류를 해제합니다. 배터리, 간식, 키트, 카세트와 안테나를 발견합니다.
2. **오락실 거리**: 놀이 신호로 경로를 연결하고 음식 비/운석 2개 이벤트를 조준합니다. 두 파괴 이벤트는 사거리 안에서 먼저 준비할 종류를 선택할 수 있습니다.
3. **중앙 신호탑**: 수면으로 회전 장벽을 안정화하고 음식 비와 운석을 연결합니다. 3개 안테나 부품을 모아 끝의 신호탑을 조사하면 엔딩입니다.

모든 구역 출구는 `z ≤ -14`에 있습니다. 근처 자원이 남아 있으면 E가 자원 수집을 먼저 수행하므로 다시 조사하세요. 안테나 부품을 놓쳤으면 지도에서 열린 이전 구역을 재탐색할 수 있습니다.

- **완전 연결**: 건강·기분·애정 각각 80 이상, 카세트 기억 2개 이상.
- **간신히 연결**: 필수 길과 안테나는 모두 연결했지만 위 돌봄/발견 조건이 부족.

어느 엔딩에서도 모모는 사라지지 않습니다. 엔딩 후에는 거대 픽셀 모모와 도시를 함께 볼 수 있습니다.

## 저장과 개인정보

`keychain-pet-matrix-v1`과 `kpm-options`에 브라우저 로컬 저장만 합니다. 저장 버전, 수치 범위, 배열, 자원/차단물 ID, 이벤트 타입과 목표를 확인합니다. 손상된 데이터와 알 수 없는 버전은 기본 상태로 안전 처리합니다. 진행 중 낙하는 저장 복원 시 다시 조준 단계로 돌아가고 자원을 중복 차감하지 않습니다. 게임 서버, DB, 인증, 광고, 분석 SDK, 추적, 개인정보 전송, eval은 없습니다. 자동 저장은 1.8초 간격이며 로컬 저장 사용 불가 시 오류를 표시합니다.

## 기술 결정과 에셋 출처

- 기존 **React 19 / Vite 7 / TypeScript / Tailwind CSS 4** 유지. CSS로 디테일한 CRT 콘솔 및 반응형 장치를 구성합니다.
- **Three.js (MIT)**: 유지보수되는 WebGL 렌더러, 모바일 지원, 자체 저폴리 모델 제작과 명시적 자원 관리. 별도 물리 엔진이나 React 3D 래퍼를 추가하지 않습니다. 단점은 모바일 GPU별 성능 차이와 큰 기본 렌더러 번들입니다.
- **SVG + CSS**: 픽셀 그리드가 선명하고 외부 이미지가 필요 없는 작은 LCD. 내부와 외부가 별도 상태를 갖지 않습니다.
- **Web Audio API**: 직접 합성한 버튼/돌봄/성공 비프음. 외부 오디오 파일 없음. 브라우저의 사용자 동작 후 음성 재생 제한을 따릅니다.
- **Lucide (ISC)**: 외부 콘솔 UI 아이콘. LCD 속 픽셀 그래픽과 도시의 기호에는 브랜드 아이콘을 사용하지 않습니다.
- **tsx (MIT)**: 추가 테스트 프레임워크 없이 TypeScript 규칙 검사를 CLI에서 실행하는 개발 도구.
- 도시 건물, 가상 간판, 민호, 장치, 모모, 음식, 효과, 배경, 지도, 오디오는 이 구현에서 직접 코드로 제작했습니다. 사진, 기존 게임 캐릭터, 상용 폰트, 외부 음악을 사용하지 않았습니다. 프로젝트 라이선스는 새로 지정하거나 변경하지 않았습니다. 제3자 라이선스는 각 패키지 LICENSE를 따릅니다.

Three.js 참고: https://threejs.org/docs/ (WebGLRenderer, PerspectiveCamera, BufferGeometry 및 리소스 dispose)

## 검증 현황 / 남은 제한

- **프로덕션 빌드 성공 확인**: 제공된 빌드 도구로 `npm run build`를 실행했습니다. Vite가 1,870개 모듈을 변환하고 단일 `dist/index.html`을 생성했습니다. 첫 성공 빌드 기준 868.29 kB, gzip 240.14 kB입니다. 이후 소규모 수정으로 최종 용량은 약간 달라질 수 있습니다.

- 자동 검사는 구현되어 있으며 위 CLI 명령 또는 브라우저 검사 메뉴에서 재현할 수 있습니다. 빌드 도구는 규칙 테스트를 자동 실행하지 않습니다.
- 이 작업 환경에는 브라우저 플레이/스크린샷/CLI 임의 실행 도구가 없으므로, **실제 E2E 플레이, 테스트 실행 통과, GPU 30/60FPS, 모바일 레이아웃과 보조 기술 검증을 완료했다고 주장하지 않습니다.** 순수 규칙의 FPS 검사는 동일 시각의 상태·궤적에 관한 것이지 실제 렌더링 프레임 속도 측정이 아닙니다.
- 설치 중 npm 감사는 **취약점 2건(낮음 1, 높음 1)**을 보고했습니다. 상세 분석과 패치 검증이 남아 있습니다. 강제 의존성 업그레이드나 스택 변경은 수행하지 않았습니다.
- 세 구역은 공통 도시 골격을 재사용하는 소규모 MVP입니다. 완전히 별개인 대규모 맵, 정교한 이동 플랫폼/고저차 물리, 자유형 게임패드 재매핑, 연속 배경음악, 전체 UI E2E 테스트는 포함하지 않습니다. 수면은 임시 정지 연출 뒤 안전 경로를 고정해 재시도 막힘을 방지하는 축약 퍼즐입니다.
- 터치는 방향 패드 방식으로 구현했으며 아날로그 가상 스틱은 아닙니다. 10~20분 플레이타임은 실측하지 않았습니다.
- 이러한 미검증/축약 항목 때문에 원문의 전체 완료 조건을 충족했다고 보고하지 않습니다.

DB, 인증, 결제, 유료 API, 개인정보 수집, 배포, 외부 공개, 계정 동기화, 라이선스 변경, 사용자 데이터 마이그레이션은 수행하지 않았습니다.
